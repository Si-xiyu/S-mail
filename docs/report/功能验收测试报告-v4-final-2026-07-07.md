# SmartMail 功能验收测试报告 v4（最终版）

> 测试日期：2026-07-07
> 分支：`fullstack/agent-demo-integration`
> 测试环境：Windows 11 · Java 17 · Spring Boot 3.3.5 · H2 (dev) · Vue 3 + Vite 6 · Python FastAPI Agent
> 服务端口：后端 8089 | 前端 5177 | Agent 8000
> **AI 配置**：`smartmail.ai.enabled: true` · DeepSeek API Key 已配置
> 测试方式：API 直连 + Agent 直连 + 前端代理验证

---

## 总体结论

**基础邮件系统全部通过验收，AI 功能核心链路已打通。** 

- 注册登录、站内收发、附件、搜索、分类、工作台视图、邮箱状态管理等基础功能完整可用。
- Agent 服务已启动，DeepSeek LLM 已激活 (llm=true)，全局 Agent 聊天可搜索后端真实邮件并返回中文回答。
- AI 自动分析管道存在 2 个后端代码 bug 导致邮件分析不生效（已定位到具体代码行）。
- 存在 BCC 隐私泄露和 2 个 API 500 错误需修复。

## 缺陷汇总

### 🔴 P0 — 阻塞性（3 项）

| # | 缺陷 | 影响 | 位置 |
| --- | --- | --- | --- |
| 1 | **BCC 隐私泄露** | TO 收件人可看到 BCC 收件人列表 | 邮件详情 `recipients` 字段 |
| 2 | **自动分析管道硬编码关闭 LLM** | 即使配了 DeepSeek API Key，自动分析永远不用 LLM | [AnalysisService.java:192-210](S-mail/backend/src/main/java/com/smartmail/analysis/service/AnalysisService.java#L192-L210) |
| 3 | **自动分析 taskId 类型不匹配** | `Long` vs `String` → Agent 422 拒绝 → 全部分析任务 FAILED | [AnalysisService.java:195](S-mail/backend/src/main/java/com/smartmail/analysis/service/AnalysisService.java#L195) |

| # | 缺陷 | 影响 | 位置 |
| --- | --- | --- | --- |
| 4 | **Sync API 500** | 轮询同步不可用 | `GET /api/v1/workspace/sync` |
| 5 | **Events API 500** | 行为信号记录不可用 | `POST /api/v1/mailbox/items/{id}/events` |
| 6 | **Agent 聊天消息接口不稳定** | 后端 500，CURRENT_MAIL 间歇解析错误 | `AgentSessionService.sendMessage()` |
