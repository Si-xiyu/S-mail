## 端到端验收脚本（推荐演示流程）

参照 [Agent 集成文档](../docs/api/agent-integration.md) 第 6.4 节，建议按以下步骤执行演示验收：

```
1. 启动 Backend (AI_ENABLED=true) → Agent → Frontend
2. 注册 demo@smail.com 和 alice@smail.com
3. demo 登录 → 开启 AI 设置 → 发送邮件给 alice（包含触发规则分析的正文）
4. alice 登录 → 确认 Inbox 新邮件出现
5. 打开邮件详情 → 确认 analysisStatus 变为 SUCCEEDED（摘要/分类/风险可见）
6. 右侧打开 "当前邮件助手" → 发送 "这封邮件需要我做什么？"
7. 观察 Agent 回复 → 确认 pendingActions 出现
8. 点击确认按钮 → 验证邮件状态变更
9. 左侧打开 "全局助手" → 发送 "帮我搜索项目相关邮件"
10. 关闭 AI Plugin → 验证基础邮件功能不受影响
```

所有测试提示词见 [agent-integration.md 第 7 节](../docs/api/agent-integration.md#7-测试提示词)。
